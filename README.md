# Интерактивная инструкция по надеванию полумаски ВМ

Мобильное веб-пособие на русском языке: шесть последовательных шагов, фотографии высокого качества, свайпы, озвучивание, проверка герметичности, уход и подбор размера.

## Локальный запуск

Откройте `index.html` в браузере или запустите любой статический HTTP-сервер в папке проекта.

## GitHub Pages

Workflow в `.github/workflows/pages.yml` публикует сайт после каждого изменения ветки `main`.
